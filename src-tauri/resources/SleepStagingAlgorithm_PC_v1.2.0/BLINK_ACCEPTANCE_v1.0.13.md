# App 工程验收清单（v1.0.13）

## 数据与滤波

- [ ] EEG1–EEG4 都进入眨眼支路；Alpha/睡眠仍固定使用 EEG1、EEG2。
- [ ] 眨眼滤波为因果 0.5–8 Hz 三阶 Butterworth SOS，状态跨 chunk 保留。
- [ ] 无效样本使用上一有效原始 EEG 补齐滤波状态，`valid` 仍为 false；未混入滤波域数据。
- [ ] EEG、IMU、valid 和 BLE 序号使用同一时间轴并完整记录。

## 校准

- [ ] UI 明确引导 3 秒睁眼安静不眨眼 + 10 秒每 0.5–1 秒自然眨眼。
- [ ] 四通道分别计算冻结的 median/MAD-quantile 中心与尺度。
- [ ] 固定配对只有 EEG1+2、EEG3+4；不使用任意跨对组合。
- [ ] 每对至少 5 个 `secondary>=2z && fused>=2z` 校准峰才启用。
- [ ] 总体有效峰比例至少 65%，中位融合强度至少 3z，否则失败。
- [ ] EEG3+4 启用时阈值为 `clip(Q25*0.30,2.5,3.25)`；只有 EEG1+2 时使用 `clip(Q25*0.45,2.5,6.0)`。
- [ ] 成功后显示 enabled pairs；失败提示检查 EEG1–4 接触并重测。
- [ ] 重新佩戴、明显接触变化或 stale 后必须显式重测。

## 在线眨眼

- [ ] 分别计算 EEG1+2 与 EEG3+4 的 `primary/secondary/fused`。
- [ ] 只在校准启用配对中选择 fused 最大的一对。
- [ ] 获胜对 `secondary>=0.60*T` 且 `fused>=T`；不允许单通道 fallback。
- [ ] 峰时刻来自配对 fused 包络，0.32 秒不应期有效。
- [ ] IMU 运动门控和 baseline stale 门控有效。

## 丢包与组状态

- [ ] 只屏蔽 invalid 之后 0.20 秒，不因未来才发生的丢包追溯删除峰。
- [ ] 连续 invalid 少于 0.35 秒不会清空此前已确认的组内眨眼。
- [ ] 连续 invalid 达 0.35 秒会清空整组。
- [ ] 仅在 invalid 位于两个峰之间且间隔为校准中位间隔 1.65–2.60 倍时，最多补一个眨眼。
- [ ] 没有 invalid 证据时不做节律补峰。

## 三次/五次

- [ ] 三次下降 10%，五次上升 10%，始终裁剪到用户最高音量。
- [ ] 五次达到时立即触发；三次至少等待 2.05 秒并给五次优先权。
- [ ] 四峰结束且第四峰低于前三峰中位强度 55% 时，可输出保留的三次。
- [ ] 三次/五次不会由单个波形的双相峰重复计数构成。
- [ ] 测试 marker 开始和 result 后都清空部分手势、待确认峰和冷却状态。
- [ ] 0/3/5 测试进行中拒绝重叠 marker。

## 基线与安全

- [ ] 眨眼中心/尺度运行中不自适应修改。
- [ ] 低运动背景健康监测每 5 秒检查；连续 3 次超限置 stale。
- [ ] stale 后暂停控制、清空手势并要求重新校准。
- [ ] 闭眼和睡眠数据不会更新睁眼安静眨眼基线。

## 日志与验证

- [ ] 提供不依赖音乐和 Alpha 的“仅眨眼验证并记录”模式，且音频动作关闭。
- [ ] 日志包含算法版本、校准配对/阈值/中心/尺度、所有 blink flag、gap recovery 和 marker/result。
- [ ] 固定回放 9/9 回归通过，已确认五次眨眼保留，历史噪声会话无新增三/五次动作。
- [ ] 单通道合成校准失败，双通道/四通道配对校准成功。
- [ ] 当前带标签回放重现 0 次 1/1、3 次 2/4、5 次 7/7、错误动作 0。
- [ ] 发布前重新采集 v1.0.13 真校准数据，每类至少 20 组，并报告混淆矩阵、Wilson 95% 区间和每小时误触数。
