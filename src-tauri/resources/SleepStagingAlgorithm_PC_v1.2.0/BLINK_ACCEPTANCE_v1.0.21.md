# App 工程验收清单 v1.0.21

- [ ] EEG1-EEG4、IMU、valid 均按 100 Hz 同步输入；断包不伪装成有效重复样本。
- [ ] 3 秒安静 + 10 秒连续眨眼校准未通过时，不执行任何眨眼音量动作。
- [ ] 3 次只降低一次音量，5 次只升高一次音量；5 次确认窗内不提前发出 3 次。
- [ ] EEG3/4 同步伪迹但 EEG1/2 无响应时，动作数为 0。
- [ ] EEG3/4 质量恶化时隔离辅助配对，EEG1/2 健康则继续工作。
- [ ] `blink_baseline_stale=true` 时动作门关闭；恢复进度可见，恢复后自动重新开启。
- [ ] 头动、咬牙、说话、触碰电极、插拔和丢包边界不产生音量动作。
- [ ] Alpha 实时占比条显示开启阈值；显示睁眼基线相对初始基线的变化。
- [ ] 闭眼和疑似睡眠期间冻结睁眼 Alpha 基线更新。
- [ ] 睡眠概率必须同时经过质量门、确认时长和冷启动门，不能单帧启停音乐。
- [ ] 日志至少记录算法版本、配对状态、模板相关性、自动恢复、0/3/5 结果和最终音量动作。
- [ ] Windows x64 与 macOS arm64 sidecar 均通过 health、校准、3/5 动作和断包 smoke test。
