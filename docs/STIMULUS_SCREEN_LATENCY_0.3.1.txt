0.3.1 屏幕光刺激时序验证
时间：2026-10-09；设备：当前 Apple Silicon Mac；最终安装应用本地运行。

验证范围
全黑刺激窗口，20 次，40 个起止事件；没有发送亮光、TTL 或 EEG 标记。
主界面处于数据采集模式，未连接头带；因此没有测量真实 EEG 并发负载。
通过的是软件时序链路、窗口创建/销毁、时钟映射和记录格式，不是光学硬件校准。

最终构建结果
相邻绘制回调间隔：P50 17 ms，P95 18 ms，最大 18 ms。
绘制请求相对计划时刻延后：P50 17 ms，P95 18 ms，最大 18 ms。
绘制请求到后台收到确认：P50 1.718 ms，P95 2.646 ms，最大 2.801041 ms。
时钟映射估计不确定度：报告下限 1 ms；WebView 计时量化时不能声称 0 ms 精度。
40 个起止事件完整结束，无绘制确认超时。
完整结果：Timing/final_screen_test/stimulus_light_ccdc57fe-6f92-4c0c-bc63-b1c6c64cfc9f_summary.json。

含义
本实现使用显示绘制回调，不使用网页定时器产生“已发光”的虚假时间。
标记记录的是绘制请求时刻；一般还需要等待合成、屏幕扫描和像素响应才真正发光。
17–18 ms 是本次软件绘制延后，不是声刺激标记延迟，也不是光学标记误差。
后台确认延迟不会被加进 EEG 标记时间戳；串口 T 则在后台收到确认后发送。
负载变化、窗口遮挡、显示刷新率和系统调度都可能增加延迟，不能承诺硬实时上界。
正式实验必须用光电传感器对屏幕亮灭进行测量，并同时采集 TTL / EEG 对齐信号。
不得把这些 Mac 数字当作 Windows 的实测结果。

声音回归
第一次静音音频自测在开始阶段收到 Xrun 驱动通知并中止；失败日志保留在 Timing/final_audio_test。
没有屏蔽该通知或把失败测试计入通过结果；具体为何出现欠载尚不能仅凭通知确定。
随后独立重测完整通过 100 次、200 个声音起止事件，44100 Hz、512 帧缓冲，无无效时间戳。
回调到事件工作线程 P50 0.031792 ms / P95 0.053625 ms / 最大 0.082917 ms。
计划输出时刻后派发延后 P50 0.251970 ms / P95 0.501764 ms / 最大 0.527654 ms。
标记探针写入刷新 P50 0.085083 ms / P95 0.202083 ms / 最大 0.375583 ms。
驱动预测音频等待 13.968254 ms；不是实测到耳声学延迟。
