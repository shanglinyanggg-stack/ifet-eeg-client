声光刺激实验版 0.3.1 — 界面与屏幕光刺激更新
日期：2026-10-09

一、界面
刺激参数从主窗口顶部移到右侧后台设置的“刺激”页。
顶部仅保留“刺激参数 / 开始声或光刺激 / 停止刺激 / 下一组”快捷按钮。
右侧设置独立滚动；关闭设置后信号区域恢复完整宽度，不再被刺激面板占用高度。
其他脑电、记录、标记和采样率功能沿用独立刺激版 0.3.0。

二、光刺激
在“刺激参数”中将“刺激类型”切换为“电脑屏幕光刺激”。
选择显示器、窗口或全屏、白色强度、亮屏时长、提示/间隔时间、次数和组数。
当前实现为定时亮屏和暗屏，不是高频闪烁或 SSVEP 刺激。
默认绘制灰度 25%，上限 80%；这是数字灰度，不是实测亮度、照度或视网膜剂量。
显示器亮度、系统色彩管理、自动亮度和夜览会改变实际光刺激，需要实验前固定并校准。
同屏全屏光刺激会遮住 EEG 窗口；需要同时观察信号时请选择窗口模式或第二显示器。

三、启动与自动标记
先进入数据采集模式，连接头带，确认实时有效数据，开始 EEG 记录，再开始刺激。
演示数据不允许启动正式刺激。
光刺激起止自动保存为“光刺激开始 / 光刺激结束”，同时记录提示、组结束和完成/中止。
事件写入当前记录对应的 *_markers.csv；详细时序保存为 stimulus_light_*.csv/json。
光刺激的时间戳是屏幕绘制请求时刻，经往返时钟同步映射到本机单调时钟和 UTC。
不是网页点击时刻，也不是光电传感器测得的真实发光时刻。
记录中保留计划时间、绘制时间、后台收到确认的时间、刷新间隔和时钟同步不确定度。
若使用 Arduino TTL，收到绘制确认后发送 T；可选结束也发送 T，起止同码需按顺序配对。
串口引脚边沿与屏幕实际发光的延迟仍需光电传感器 / 示波器测量。

四、停止与异常
主窗口“停止刺激”、刺激窗口 Esc 均可请求停止；组间可按空格继续。
EEG 无有效数据超过 2.5 秒、屏幕隐藏/最小化、绘制确认超时或串口失败时停止。
无法确认实际结束时间的异常采用 forced_abort_uncertain，不伪造精确光刺激结束时刻。
刺激进行中不能切换设备采样率或停止记录，避免把事件写到错误数据文件。

五、时序自测
“全黑屏幕时序自测”执行 20 次无发光切换测试，不发送 TTL、不写入 EEG 标记。
它测量软件绘制请求、刷新间隔、跨窗口通信和时钟同步；不测量真实光学延迟。
“静音音频时序自测”继续用于驱动预测输出时刻和事件派发评估。
正式研究应在目标电脑、目标显示器、实际 EEG 采集负载下用光电传感器和 TTL 做回环校准。
不能把 Mac 测得数字直接当作 Windows 延迟。
